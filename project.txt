Название проекта: Учебный веб-проект

Описание проекта:
Небольшой учебный проект для практики основ веб-разработки. Проект предназначен для закрепления навыков создания структуры сайта и работы с GitHub.

Функции:
1. Отображение главной страницы проекта.
2. Навигация между основными разделами сайта.
3. Адаптация интерфейса для мобильных устройств
